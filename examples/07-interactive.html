What is Torque UI?

Torque UI is a zero-JavaScript CSS framework inspired by SemanticUI and Tailwind. It uses modern CSS features like :has(), @layer, color-mix(), and native <details>/<summary> to deliver interactive components without any JS.

How do components work?

Components use CSS-only techniques: hidden checkboxes/radios for state, :has() and :checked for interactivity, native <details> for disclosure, and @layer for cascade control. No JavaScript required.

Browser support?

Torque UI targets modern browsers that support :has(), @layer, and color-mix(). This includes Chrome 123+, Safari 17.5+, and Firefox 128+.
