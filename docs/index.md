<section class="tui-grid tui-grid-md-2 tui-gap-6 tui-mb-12 tui-items-start" id="install">
  <div class="tui-card">
    <div class="tui-card-header"><h2>Description</h2></div>
    <div class="tui-card-body">
      <p><strong>Torque UI</strong> is a zero-JavaScript CSS framework. Interactivity comes from
        native HTML - hidden checkboxes and radios, <code>&lt;details&gt;</code>,
        <code>popover</code>, <code>&lt;dialog&gt;</code> - driven by <code>:has()</code>,
        <code>:checked</code> and cascade layers; not a single script ships with it.</p>
      <p>The whole palette derives from <strong>one brand colour</strong>, and nine
        <code>@layer</code>s settle precedence without a single <code>!important</code>. Flex and
        grid components space their children with <code>gap</code> and carry no outer margins.
        WCAG AA contrast, visible focus rings, reduced-motion, forced-colors and high-contrast
        support come by default.</p>
      <p>This very website is built with it.</p>
    </div>
  </div>

  <div class="tui-card">
    <div class="tui-card-header"><h2>Installation</h2></div>
    <div class="tui-card-body">
      <p class="tui-text-2">Link one stylesheet and start composing. No build step, no runtime, no
        configuration:</p>
      <div class="pill tui-input-group">
        <span class="tui-input-addon"><code><span class="str">&lt;link</span> rel=<span class="str">"stylesheet"</span> href=<span class="str">"dist/tui-all.css"</span><span class="str">&gt;</span></code></span>
        {%- include copy-button.html label="Copy the stylesheet tag" -%}
      </div>

      <p class="tui-text-2">Or, for the modular source, loaded through <code>@import … layer()</code>:</p>
      <div class="pill tui-input-group">
        <span class="tui-input-addon"><code><span class="str">&lt;link</span> rel=<span class="str">"stylesheet"</span> href=<span class="str">"src/tui.css"</span><span class="str">&gt;</span></code></span>
        {%- include copy-button.html label="Copy the modular stylesheet tag" -%}
      </div>

      <p class="tui-text-2">Re-theme everything by overriding one variable:</p>
      <div class="pill tui-input-group">
        <span class="tui-input-addon"><code><span class="cmd">:root</span> { --tui-brand: <span class="str">#e11d48</span>; }</code></span>
        {%- include copy-button.html label="Copy the brand override" -%}
      </div>
    </div>
  </div>
