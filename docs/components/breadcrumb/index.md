A breadcrumb shows where the current page sits in a hierarchy. `.tui-breadcrumb` is a wrapping flex row of small text: every child except the last is followed by a `/` separator generated by CSS, so the markup holds only the crumbs themselves. It has `--tui-spacing-2` padding above and below, none on the inline sides, and a `--tui-spacing-2` gap between crumbs; the separator renders in `--tui-text-3`.

## Basic

Links inside the trail are muted (`--tui-text-2`) with no underline and turn brand-coloured on hover. Mark the current page with `.tui-breadcrumb-current`: it renders in `--tui-text-1` at medium weight and, being last, gets no separator. Use a `<nav>` with an `aria-label` so assistive technology announces the trail as navigation.

{% include demo.html file="basic.html" %}

| Class | Effect |
|---|---|
| `.tui-breadcrumb` | Wrapping flex row, `--tui-text-sm`, slash separators after every child but the last |
| `.tui-breadcrumb-current` | The current page: `--tui-text-1`, medium weight |

## As a list

The container also works as an `<ol>`: the list marker is removed and each `<li>` becomes an inline-flex item with its own margin reset, so the separators land in the same place. Each item is itself a small flex row with a `--tui-spacing-2` gap, so an icon can sit next to its label without extra markup.
